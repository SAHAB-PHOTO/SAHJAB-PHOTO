# طيف — TAYF · مختبر الضوء واللون للمصوّر

> ليس محرّر صور آخر. **طيف مدرّبٌ بصري** يحلّل تكوين صورتك وضوءها ولونها، ويعلّمك كيف تفكّر كعدسة محترفة — بالكامل داخل متصفحك، بلا خوادم ولا رفع للصور.

## الفكرة المبتكرة

أغلب تطبيقات التصوير تتنافس على *الفلاتر والتعديل*. **طيف** يسلك طريقاً مختلفاً: بدل أن يجمّل صورتك، **يشرحها ويقيّمها ويدرّبك**. يحوّل المفاهيم النظرية (القاعدة الثلثية، الحلزون الذهبي، مركز الثقل البصري، توازن التعريض، انسجام الألوان) إلى تحليل مرئي فوري على صورتك أنت.

## المزايا

| الميزة | الوصف |
|--------|--------|
| 🎯 **محلّل التكوين** | يحسب **مركز الثقل البصري** عبر السطوع وكثافة الحواف (Sobel)، ويقارنه بنقاط القوة الذهبية، ويعطي **درجة من 100** مع نصائح مخصّصة. |
| 🖼️ **طبقات تكوين تفاعلية** | القاعدة الثلثية · الحلزون الذهبي · الأقطار · مؤشّر مركز الثقل — تُفعّل وتُطفأ فوق صورتك. |
| 🎨 **استخراج لوحة الألوان** | تكميم لوني (k-means) يستخرج 6 ألوان سائدة بأكوادها، قابلة للنسخ بنقرة. |
| 🌡️ **كشف المزاج** | يقيس الدفء والتشبّع والتباين ويصنّف الصورة (دافئ نابض / بارد درامي / سينمائي / مونوكروم…). |
| 📊 **هيستوجرام حي** | توزيع الإضاءة مع نصائح تعريض (ظلال مقصوصة / إبرازات محروقة / منخفض ـ عالي المفتاح). |
| ⬇️ **بطاقة تحليل** | يولّد بطاقة PNG أنيقة (1080×1350) جاهزة للمشاركة. |
| 🔒 **خصوصية مطلقة** | كل المعالجة عبر Canvas داخل المتصفح. لا رفع، لا تخزين، يعمل دون إنترنت. |

## التشغيل

لا يحتاج أي بناء أو تثبيت — ملفات ثابتة:

```bash
# أبسط طريقة
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو افتح `index.html` مباشرة في المتصفح.

## كيف يعمل التحليل؟

1. تُرسم الصورة على لوحة تحليل مصغّرة (220px) لأداء سريع.
2. **مركز الثقل** = مجموع موزون لإشارات الحواف (Sobel) وانحراف السطوع، ثم مركز الكتلة.
3. **الدرجة** = قرب مركز الثقل من تقاطعات الأثلاث (50%) + توازن التعريض (28%) + جودة التباين (22%).
4. **الألوان** عبر k-means (8 تكرارات، 6 مراكز) مرتّبة حسب الشيوع.
