# نُخبة — Nukhba · محطّة الفرز الفوري

> **افرز آلاف الصور في دقائق لا ساعات.** أداة فرز (Culling) سريعة تعمل بالكامل داخل متصفحك — مجاناً، بخصوصية تامة، ودون إنترنت.

![نوع](https://img.shields.io/badge/نوع-أداة_فرز_صور-7ee8fa) ![تقنية](https://img.shields.io/badge/تقنية-Vanilla_JS_·_Canvas-feb47b) ![خصوصية](https://img.shields.io/badge/يعمل-دون_إنترنت_·_100%25_محلي-5fe39a)

## المشكلة التي يحلّها (مدعومة ببحث السوق)

الفرز هو **القاتل الصامت** في عمل المصوّر:
- المصوّر المحترف يقضي **20–30 ساعة أسبوعياً** أمام الشاشة، و**80%** من وقته في *الانتقاء* لا التصوير.
- البحث عن الملفات وحده يكلّف ما يصل إلى **78,000$ سنوياً** من الوقت الضائع.

وأدوات الفرز الحالية تترك **فجوة واضحة**:
- 🌩️ **سحابية** (FilterPixel وغيرها) → لا تعمل دون إنترنت، كابوس لمصوّري الوجهات والعمل الحسّاس.
- 💸 **مدفوعة باشتراك** ($15+/شهر) → إرهاق اشتراكات.
- 🔓 **ترفع صور العميل** إلى خوادمها → قلق خصوصية حقيقي.

**نُخبة يسدّ هذه الفجوة بالضبط:** مجاني · محلي · خاص · فوري.

## المزايا

| الميزة | التفصيل |
|--------|---------|
| ⚡ **فرز بسرعة الكيبورد** | تنقّل بالأسهم، قبول/رفض، تقييم نجوم 1–5، دون لمس الفأرة — يقفز تلقائياً للصورة التالية بعد الحكم. |
| 🔬 **كشف الحدّة** | يحلّل تركيز كل صورة عبر **تباين Laplacian** ويُعلِّم الصور المهتزّة/الناعمة تلقائياً، مع فلتر مخصّص لها. |
| 🔗 **تجميع اللقطات المتسلسلة** | يجمع الصور المتشابهة عبر **بصمة إدراكية (aHash + مسافة هامِنغ)**، ويرشّح **الأوضح** في كل دفعة. اضغط `G` للقفز إليها. |
| 🔍 **فحص التركيز 100%** | تكبير فوري للتأكد من حدّة العين/التفاصيل قبل القبول. |
| 🧮 **فلاتر ذكية** | الكل / غير المفروزة / المقبولة / المرفوضة / ★3+ / غير الواضحة. |
| ⬓ **مقارنة جنباً إلى جنب** | يعرض لقطات المجموعة معاً مع مؤشّر الحدّة، تختار الفائزة بنقرة فتُقبَل وتُرفَض البقية (`C`). |
| 📷 **دعم RAW** | يفتح ملفات **CR2/CR3/NEF/ARW/RAF/ORF/RW2/DNG/PEF…** عبر استخراج أكبر **معاينة JPEG مضمّنة** من بايتات الملف — كل ذلك محلياً دون مكتبات. |
| 💾 **حفظ الجلسة تلقائياً** | تُحفظ كل قراراتك وتحليلك في **IndexedDB**؛ أعد فتح المجلد لاحقاً فتُستعاد فوراً (ويُتخطّى إعادة التحليل). بصمة الملف = الاسم + الحجم + تاريخ التعديل. |
| 📤 **تصدير ثلاثي** | (1) قائمة أسماء `.txt` لفلتر **Lightroom / Capture One**. (2) ملفات **XMP** بالتقييم والعلامة داخل `.zip` تقرأها Lightroom/Bridge. (3) **الصور الأصلية المقبولة نفسها** داخل `.zip`. كل ذلك عبر **مولّد ZIP بلغة JS خالصة دون أي مكتبة**. |
| 🔒 **خصوصية مطلقة** | كل المعالجة عبر Canvas. الصور لا تُرفع، لا تُخزَّن، يعمل دون إنترنت تماماً. |

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|--------|---------|
| `→` `←` | التنقّل بين الصور |
| `P` | قبول (Pick) |
| `X` | رفض |
| `1`–`5` | تقييم بالنجوم · `0` لإزالته |
| `Z` / `مسافة` | تكبير 100% لفحص التركيز |
| `G` | القفز لأوضح صورة في المجموعة |
| `C` | مقارنة لقطات المجموعة جنباً إلى جنب · `Esc` للإغلاق |

## التشغيل

ملفات ثابتة، بلا بناء ولا تثبيت:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو افتح `index.html` مباشرة. جرّب زر **«صور تجريبية»** لتجربة كشف الحدّة والتجميع فوراً.

## كيف يعمل التحليل؟

1. كل صورة تُرسم على لوحة 256px → **الحدّة** = تباين مرشّح Laplacian (مقياس لوغاريتمي 0–100).
2. **البصمة** = aHash بحجم 8×8 (64 بت). صورتان تُعتبران من نفس الدفعة إذا كانت **مسافة هامِنغ ≤ 8**.
3. أفضل صورة في المجموعة = الأعلى حدّةً.
4. كل ذلك يجري بالتتابع في الخلفية دون تجميد الواجهة.

>
