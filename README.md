# 🇩🇿 طلبات الجزائر - Talabat Algeria

موقع توصيل طعام بطابع جزائري 100% - نسخة طبق الأصل من تطبيق طلبات مع تخصيص كامل للسوق الجزائري.

## ✨ المميزات

- 🎨 **تصميم بألوان العلم الجزائري** : أخضر، أبيض، أحمر، ذهبي
- 🍲 **أكلات جزائرية أصيلة** : كسكسي، مْحاجب، شخشوخة، كرنتيكا، زلابية، مقروط...
- 🏙️ **توصيل في 48 ولاية** : الجزائر العاصمة، وهران، قسنطينة، عنابة، سطيف...
- 💳 **طرق دفع جزائرية** : كاش، CIB، Edahabia، BaridiMob
- 🗣️ **بالدارجة الجزائرية** : "وين راح كرشك ؟"، "اطلب لباب دارك"...
- 📱 **متجاوب 100%** : يعمل على الموبايل، التابلت والكمبيوتر
- 🛒 **سلة تسوق كاملة** : إضافة/حذف، تعديل الكمية، حفظ في localStorage

## 📁 هيكل المشروع

```
SAHJAB-PHOTO/
├── index.html          # الصفحة الرئيسية
├── restaurants.html    # قائمة المطاعم مع الفلاتر
├── restaurant.html     # تفاصيل المطعم والقائمة
├── cart.html          # سلة التسوق وإتمام الطلب
├── css/
│   └── style.css      # التصميم بألوان العلم الجزائري
└── js/
    └── app.js         # المنطق + بيانات المطاعم
```

## 🚀 طريقة التشغيل

افتح `index.html` في المتصفح، ولا شغّل سيرفر محلي :

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
