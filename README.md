# 📰 نَبأ — NABA News

> **«الخبرُ اليقين، أولاً»**

موقع إخباري احترافي عربي (RTL) نسخة عصرية مستوحاة من كبرى المواقع الإخبارية
العالمية (BBC / CNN / الجزيرة). الاسم **نَبأ — NABA** علامة جديدة جذّابة
وسهلة الحفظ، ومعناها «الخبر المهم».

## ✨ المميزات

- **تصميم احترافي متجاوب** يعمل على الهاتف والحاسوب.
- **واجهة عربية (RTL)** بخطوط حديثة (Tajawal / Cairo / Amiri).
- **الوضع الليلي/النهاري** مع حفظ تفضيل المستخدم.
- **شريط الأخبار العاجلة** المتحرّك.
- **قسم البطل (Hero)** للأخبار الرئيسية + شبكة بطاقات.
- **أقسام متعددة:** العالم، سياسة، اقتصاد، رياضة، تكنولوجيا، ثقافة، صحة، علوم.
- **صفحة مقال كاملة** مع مقالات ذات صلة ووسوم وأزرار مشاركة.
- **شريط جانبي:** الأكثر قراءة، النشرة البريدية، مؤشرات الأسواق، مختارات المحرّر.
- **بدون أي صور خارجية** — خلفيات متدرّجة تعمل حتى دون إنترنت.
- **إدارة سهلة للأخبار** عبر ملف `js/data.js` فقط.

## 🗂️ الهيكل

```
.
├── index.html        # الصفحة الرئيسية
├── category.html     # صفحة القسم (?cat=tech ...)
├── article.html      # صفحة المقال (?id=a1 ...)
├── css/style.css     # نظام التصميم الكامل
└── js/
    ├── data.js       # الأخبار والأقسام (عدّلها لإضافة أخبار)
    └── main.js       # منطق العرض والتفاعل
```

## 🚀 التشغيل

افتح `index.html` مباشرة في المتصفّح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## ✏️ إضافة خبر جديد

أضف عنصراً جديداً إلى مصفوفة `NABA_ARTICLES` في `js/data.js`:

```js
{
  id: "a13", category: "tech", img: 5,
  title: "عنوان الخبر",
  lead: "ملخص قصير للخبر...",
  author: "اسم الكاتب", date: "قبل ساعة", read: 4,
  tags: ["وسم1", "وسم2"],
}
```
