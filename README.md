# 🛒 RafikExpress — رفيق إكسبريس

> المتجر الإلكتروني الجزائري الأول — سوق إلكتروني (Marketplace) احترافي مستوحى من
> تجربة AliExpress، بهوية جزائرية أصلية، واجهة عربية RTL، وكل وسائل الدفع الإلكتروني.

[![Build](https://img.shields.io/badge/build-passing-brightgreen)]() [![Stack](https://img.shields.io/badge/Vite-React-blue)]() [![RTL](https://img.shields.io/badge/RTL-العربية-orange)]()

---

## ✨ المميزات

- 🇩🇿 **واجهة عربية كاملة RTL** بخطوط عصرية (Tajawal / Cairo).
- 🏠 **صفحة رئيسية احترافية**: سلايدر متحرك، فئات، **عروض البرق ⚡ بعدّاد تنازلي**، ومنتجات مختارة.
- 📦 **صفحة منتج متكاملة**: معرض، خصومات، كمية، تقييمات، مواصفات، بائع، ومنتجات مشابهة.
- 🔎 **بحث وفلترة وترتيب** (السعر / التقييم / الأكثر مبيعاً / توصيل مجاني).
- 🛒 **سلة ذكية** مع شريط تقدّم للتوصيل المجاني، قسائم خصم، وحفظ تلقائي.
- 💳 **كل وسائل الدفع الجزائرية والدولية** (انظر الأسفل).
- 🚚 **دفع عند الاستلام + توصيل للـ58 ولاية** (منزل / مكتب Stop Desk).
- 🏍️ **شركات التوصيل الجزائرية** للاختيار في الدفع مع سعر ومدّة وتقييم لكل شركة.
- ❤️ **مفضلة**، 👤 **حساب مستخدم**، 🏪 **لوحة تحكم بائع** بإحصائيات ورسوم.
- 🔔 إشعارات Toast، وضع داكن، وتصميم متجاوب بالكامل.

---

## 💳 وسائل الدفع المدعومة

| المجموعة | الوسائل |
|---|---|
| **محلية جزائرية** | بطاقة **CIB** · بطاقة **الذهبية Edahabia** (عبر **SATIM**) · **BaridiMob** · تحويل **CCP** |
| **بطاقات دولية** | **Visa / MasterCard** (عبر Stripe) |
| **محافظ رقمية** | **PayPal** · **Google Pay / Apple Pay** · عملات رقمية (USDT/BTC) |
| **عند الاستلام** | **الدفع نقداً عند الاستلام** (Cash on Delivery) ✅ |

> الواجهة جاهزة للتكامل الحقيقي. المفاتيح تُضاف في `.env` (انظر `.env.example`)،
> وحالياً تُستخدم **محاكاة آمنة** لمعالجة الطلب دون تخزين بيانات البطاقة.

## 🚚 شركات التوصيل المدعومة

تظهر في صفحة الدفع للاختيار بينها، ويتغيّر سعر التوصيل تلقائياً حسب الشركة ونوع التوصيل:

| الشركة | المدّة | التغطية | عند الاستلام |
|---|---|---|---|
| **ياليدين** (Yalidine) | 24–72 سا | 58 ولاية | ✅ |
| **ZR Express** | 48–72 سا | 58 ولاية | ✅ |
| **مايسترو** (Maystro Delivery) | 24–48 سا | 48 ولاية | ✅ |
| **نوست** (Noest Express) | 24–72 سا | 58 ولاية | ✅ |
| **غيبكس** (Guepex Express) | 48–96 سا | 48 ولاية | ✅ |
| **بريد الجزائر — EMS** | 3–6 أيام | 58 ولاية | — |

> الأسعار والمدد تقديرية للعرض، وتُضبط لاحقاً عبر لوحة الإدارة أو API كل شركة.

## 🚀 التشغيل

```bash
npm install      # تثبيت الحزم
npm run dev      # تشغيل بيئة التطوير على http://localhost:8080
npm run build    # بناء نسخة الإنتاج
npm run preview  # معاينة نسخة الإنتاج
```

## 🗂️ هيكل المشروع

```
src/
├── components/      # المكوّنات (Navbar, Footer, ProductCard, ...) + ui/
│   └── ui/          # عناصر shadcn-style (button, badge, toast, Rating)
├── pages/           # الصفحات (Home, Product, Cart, Checkout, ...)
├── context/         # CartContext + WishlistContext (مع localStorage)
├── data/            # بيانات تجريبية (products, categories, payments, wilayas)
├── lib/             # أدوات مساعدة (cn, formatDZD, ...)
├── App.tsx          # التوجيه (React Router)
└── main.tsx         # نقطة الدخول
```
