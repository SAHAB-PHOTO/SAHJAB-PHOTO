# 📸 أكاديمية سهاب للتصوير الفوتوغرافي — SAHJAB PHOTO

أول أكاديمية عربية متكاملة لتعليم التصوير الفوتوغرافي: منصة تعليم إلكتروني (LMS) بواجهة عربية كاملة (RTL)، من الصفر إلى الاحتراف.

## ✨ المزايا

- **مكتبة دورات متكاملة** — 12 دورة و300+ درس تغطي: الأساسيات، التكوين، البورتريه، الطبيعة، المنتجات، الشارع، الفلكي، الماكرو، الصحفي، فوتوشوب، لايتروم، الإضاءة الاحترافية، وإدارة أعمال التصوير.
- **مناهج منظمة** — وحدات ودروس متدرجة، معاينات مجانية، مشاريع عملية، واختبارات تفاعلية بعد كل وحدة.
- **نظام حسابات وتقدّم** — تسجيل طلاب، تتبع إكمال الدروس، نتائج الاختبارات، ولوحة تحكم شخصية.
- **شهادات موثّقة** — تصدر تلقائيًا برمز تحقق فريد عند إكمال الدورة واجتياز اختباراتها، قابلة للطباعة/حفظ PDF.
- **نموذج تجاري متعدد** — دورات فردية بملكية مدى الحياة، واشتراك شهري/سنوي يفتح كامل المكتبة، مع صفحة دفع (محاكاة جاهزة للاستبدال ببوابة حقيقية).
- **تصميم عصري متجاوب** — هوية بصرية داكنة/ذهبية تناسب عالم التصوير، تعمل على الجوال والحاسوب، مبنية بلا أي إطار عمل خارجي.

## 🚀 التشغيل

الموقع ثابت بالكامل — لا يحتاج تثبيت أي شيء:

```bash
# محليًا
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو انشره مباشرة على GitHub Pages / Netlify / Vercel.

## 🗂️ البنية

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `courses.html` | كتالوج الدورات (بحث + فلاتر) |
| `course.html?id=…` | تفاصيل الدورة والمنهج |
| `lesson.html` | مشغّل الدروس + الاختبارات + تتبع التقدّم |
| `pricing.html` / `checkout.html` | الباقات وصفحة الدفع |
| `register.html` / `login.html` | إنشاء حساب / دخول |
| `dashboard.html` | لوحة الطالب: دوراتي، شهاداتي، المدفوعات، الملف |
| `assets/js/data.js` | **كل المحتوى**: الدورات والمناهج والأسعار |
| `assets/js/app.js` | منطق الحسابات والتسجيل والتقدّم والشهادات |
| `assets/css/style.css` | نظام التصميم |
| `docs/admin-guide.html` | دليل المسؤولين والمعلمين |

## ⚠️ ملاحظة النسخة التجريبية

الحسابات والتقدّم والمدفوعات تُخزَّن محليًا في متصفح المستخدم (`localStorage`) لأغراض العرض. خطة الانتقال للإنتاج (Backend + Stripe/بوابات محلية + قاعدة بيانات) موثّقة بالتفصيل في [دليل المسؤولين](docs/admin-guide.html).
