1. بنية المنصة

المنصة الحالية نسخة أمامية متكاملة (Frontend) لا تتطلب خادمًا، ما يجعلها قابلة للنشر فورًا على أي استضافة ثابتة (GitHub Pages، Netlify، Vercel). البيانات التجريبية للطلاب تُخزَّن في متصفح المستخدم عبر localStorage.

  • index.html — الصفحة الرئيسية (البطل، المزايا، الدورات، المسارات، المدربون، الآراء، الأسئلة).
  • courses.html — كتالوج الدورات مع بحث وفلاتر.
  • course.html?id=… — صفحة تفاصيل الدورة والمنهج.
  • lesson.html?course=…&m=…&l=… — مشغّل الدروس مع تتبع التقدّم، و&quiz=1 للاختبارات.
  • register.html / login.html — التسجيل والدخول.
  • dashboard.html — لوحة الطالب: الدورات، الشهادات، المدفوعات، الملف الشخصي.
  • pricing.html / checkout.html — الباقات وصفحة الدفع (محاكاة).
  • assets/js/data.js — قلب المحتوى: جميع الدورات والمناهج والأسعار.
  • assets/js/app.js — منطق الحسابات والتسجيل والتقدّم والشهادات.
  • assets/css/style.css — نظام التصميم الكامل.

2. إدارة الدورات

إضافة دورة جديدة

افتح assets/js/data.js وأضف كائنًا جديدًا داخل مصفوفة COURSES بهذه البنية:

{
  id: "wedding",                    // معرّف فريد بالإنجليزية (يظهر في الرابط)
  title: "تصوير حفلات الزفاف",       // اسم الدورة
  category: "مناسبات",              // التصنيف (يظهر في الفلاتر تلقائيًا)
  level: "متقدم",                   // مبتدئ | متوسط | متقدم
  price: 79, oldPrice: 99,          // السعر والسعر قبل الخصم (اختياري)
  free: false,                      // اجعلها true لدورة مجانية
  rating: 4.8, students: 0, hours: 12, lessonsCount: 24,
  instructor: "khaled",             // معرّف مدرّب من INSTRUCTORS
  gradient: ["#1a1a2e", "#c9a227"], // لونا خلفية البطاقة
  icon: "💍",                       // أيقونة البطاقة
  short: "وصف قصير يظهر في البطاقة",
  goals: ["الهدف الأول", "الهدف الثاني"],
  modules: [ /* الوحدات — انظر القسم التالي */ ],
}
💡 بعد الحفظ ورفع التعديل، تظهر الدورة تلقائيًا في الكتالوج والفلاتر والصفحة الرئيسية دون أي خطوة إضافية.

تعديل أو حذف دورة

  • التعديل: عدّل حقول الكائن مباشرة (السعر، الوصف، الدروس…).
  • الحذف: احذف الكائن من المصفوفة. تأكد من إزالة معرّفها من مصفوفات TRACKS إن كانت ضمن مسار.

3. إدارة الدروس والاختبارات والمشاريع

بنية الوحدة

{
  title: "الوحدة الأولى: العنوان",
  lessons: [
    { title: "عنوان الدرس", dur: "18د",
      freePreview: true,          // اختياري: معاينة مجانية لغير المسجلين
      project: true,              // اختياري: يميّز الدرس كمشروع عملي
      content: "النص التعليمي المرافق للفيديو…" },
  ],
  quiz: {                          // اختياري: اختبار نهاية الوحدة
    title: "اختبار الوحدة",
    questions: [
      { q: "نص السؤال؟", options: ["أ", "ب", "ج", "د"], answer: 1 },
      // answer = رقم الخيار الصحيح (يبدأ من 0)
    ],
  },
}

رفع الفيديوهات

في النسخة التجريبية يظهر إطار فيديو تجريبي. عند توفر المحتوى:

  1. ارفع الفيديو إلى مزوّد بث (Vimeo Pro، Bunny Stream، Cloudflare Stream — كلها تدعم حماية المحتوى).
  2. أضف حقل video: "رابط التضمين" إلى كائن الدرس.
  3. في lesson.html استبدل div.video-frame بعنصر iframe يقرأ الحقل الجديد.

قواعد الشهادات

تصدر الشهادة تلقائيًا برمز تحقق فريد عندما: يُكمل الطالب 100% من الدروس و يجتاز كل اختبارات الدورة بنسبة 60% فأكثر. يمكن تعديل النسبة في دالة maybeIssueCertificate داخل app.js.

4. إدارة الأسعار والباقات

  • سعر دورة: حقل price في كائن الدورة، وoldPrice لإظهار خصم.
  • الباقات: مصفوفة PLANS في data.js — عدّل الأسعار والمزايا ومدد الاشتراك.
  • الاشتراك النشط يفتح جميع الدورات تلقائيًا (منطق Enroll.isEnrolled).

5. حسابات الطلاب والتقدّم والشهادات

  • حسابات الطلاب في النسخة التجريبية محلية في متصفح كل مستخدم (localStorage) تحت المفاتيح sahab_users وsahab_session.
  • يتتبع النظام: الدروس المكتملة، نتائج الاختبارات، الشهادات، المدفوعات، وحالة الاشتراك.
  • الطالب يدير كل شيء من dashboard.html: متابعة التقدم، عرض وطباعة الشهادات، سجل الفواتير، إلغاء التجديد.

6. الانتقال إلى الإنتاج

⚠️ النسخة الحالية مثالية للعرض والتحقق من التجربة. قبل استقبال طلاب ومدفوعات حقيقية، نفّذ الخطوات التالية.

الخلفية (Backend)

  1. أنشئ خدمة API (يوصى بـ Laravel أو Node.js/Express أو Django) بقاعدة بيانات PostgreSQL أو MySQL.
  2. انقل بيانات data.js إلى جداول: courses، modules، lessons، quizzes، users، enrollments، progress، certificates، payments.
  3. استبدل كائنات Auth / Enroll / Payments في app.js بنداءات fetch إلى الـ API مع جلسات JWT وتجزئة bcrypt لكلمات المرور.

الدفع الحقيقي

  1. أنشئ حسابات لدى بوابة عالمية (Stripe / PayPal) وبوابة إقليمية للمدفوعات المحلية (مثل Moyasar / Tap / Paymob) حسب أسواقك.
  2. استبدل محاكاة checkout.html بجلسات دفع من الخادم (Stripe Checkout مثلًا) — لا تُدخل بيانات البطاقات في صفحاتك مطلقًا.
  3. فعّل Webhooks لتأكيد الدفع وتفعيل التسجيل/الاشتراك من الخادم.

الأمان والنشر

  • شهادة SSL إلزامية (مجانية عبر Let's Encrypt أو تلقائية على Netlify/Vercel/Cloudflare).
  • حماية DDoS وCDN عبر Cloudflare.
  • ربط Google Analytics 4 وSearch Console، وإضافة sitemap.xml عند اكتمال الصفحات.
  • نسخ احتياطي يومي لقاعدة البيانات، وبيئة staging منفصلة للتجارب.
